# Bot Engine Subsystem

## Overview
Implements the autonomous player bot subsystem (`libbot_engine.so` on Linux, statically linked on Windows) and its hot-reloadable loader (`BotEngineLoader`), host-owned ABI isolation services (`BotAuditSink`, `botHostScheduleEvent`, `botHostMakePlayer`), and OS portability layer (`bot_platform.hpp`). Manages bot lifecycle, hibernation and virtual simulation, 2D A* and multi-floor portal navigation (`botnav`), solo and party hunting, combat/spell/rune evaluation, PvP/gang-PK tactics, depot sparring, ambient city liveness (POIs, houses, shrines, bed sleep, disguised rescues, fishing, chat), passive spawn auto-claim and learned hunt-danger zones, fruitless-fight/death-loop recovery, player command verbs, authored CSV data loading/editing, and external brain telemetry/intent IPC (`botbrain`).

## Interface
- `IBotEngine`, `BotState`, `BotReloadSnapshot`, `BotReloadEntry`, `BotPlayerSnapshot`, `HuntScript`, `Waypoint`, `CityRouteGraph`, `BotPOI`, `BotAIState`, `POIType`, `HuntPhase`, `FloorChangeState` (`[bot_engine_interface.hpp:IBotEngine]`, `[bot_engine_interface.hpp:BotState]`, `[bot_engine_interface.hpp:HuntScript]`, `[bot_engine_interface.hpp:Waypoint]`): Public ABI boundary between the main server binary and the bot engine.
- `BotEngineLoader`, `getBotEngineInstance`, `getBotEngineIfLoaded`, `g_botEngine` (`[bot_engine_loader.hpp:BotEngineLoader]`, `[bot_engine_loader.cpp:BotEngineLoader]`, `[bot_engine.hpp:getBotEngineInstance]`, `[bot_engine.hpp:g_botEngine]`): Singleton dynamic library loader supporting two-phase `prepareReload()` / `commitReload()` / `initialize()` with private `.so` snapshots and state handoff.
- `BotAuditSink` (`[bot_audit_sink.hpp:BotAuditSink]`, `[bot_audit_sink.cpp:BotAuditSink]`): Main-binary pImpl singleton synchronously writing NDJSON audit records (`write`, `writeCmd`) whose toggle/kinds/watch settings persist across `/cavebot reload`.
- `botHostScheduleEvent`, `botHostMakePlayer` (`[bot_host.hpp:botHostScheduleEvent]`, `[bot_host.hpp:botHostMakePlayer]`, `[bot_host.cpp:botHostScheduleEvent]`): Executable-owned Task and `std::make_shared<Player>` allocators so control-block vtables outliving `dlclose()` never point into an unloaded engine image.
- `bot_platform.hpp`: Single cross-platform OS wrapper isolating Windows/POSIX primitives and `ssize_t` outside the engine TUs.
- `botEngineAbiTag`, `prepareBotEngine`, `createBotEngine`, `destroyBotEngine` (`[bot_engine_abi.hpp:BotEngineAbiFunc]`, `[bot_engine.cpp:botEngineAbiTag]`, `[bot_engine.cpp:createBotEngine]`): Exported `extern "C"` factory and ABI verification hooks in `libbot_engine.so`.
- `BotEngine` (`[bot_engine_impl.hpp:BotEngine]`, `[bot_engine.cpp:BotEngine]`): Concrete implementation of `IBotEngine` spanning 27 engine TUs across lifecycle (`bot_engine.cpp`), tick/virtual sim (`bot_tick.cpp`), navigation/floor transitions (`bot_nav.cpp`, `bot_waypoint.cpp`, `bot_zgraph.cpp`), hunting/luring/kiting/looting (`bot_hunt.cpp`), party hunts/trails (`bot_party.cpp`), combat/PvP/gang-PK (`bot_combat.cpp`), depot sparring (`bot_spar.cpp`), fruitless-fight/death-loop recovery (`bot_recovery.cpp`), bed sleep and disguised rescue teleports (`bot_realism.cpp`), passive spawn auto-claim and learned danger zones (`bot_learning.cpp`), player command verbs (`bot_verb.cpp`), POIs/houses/shrines/fishing/travel/roam (`bot_poi.cpp`, `bot_house.cpp`, `bot_shrine.cpp`, `bot_supply.cpp`, `bot_travel.cpp`, `bot_roam.cpp`), liveness/chat (`bot_liveness.cpp`, `bot_chat.cpp`), CSV data/editing (`bot_data.cpp`, `bot_csv.cpp`, `bot_csvedit.cpp`), debug/commands (`bot_debug.cpp`, `bot_command.cpp`), and brain IPC (`bot_brain.cpp`).
- `botnav::findPath`, `botnav::PathNodePool`, `botnav::PathParams` (`[bot_pathcore.hpp:botnav::findPath]`, `[bot_pathcore.hpp:botnav::PathNodePool]`): Dependency-free 2D A* pathfinding kernel shared between the live server and `tools/botnavsim`.
- `botnav::classifyWalkSync`, `botnav::WalkSync`, `botnav::WalkSyncResult`, `botnav::retryQueue` (`[bot_walksync.hpp:botnav::classifyWalkSync]`): Dependency-free walk-desync classifier detecting off-line steps (`Unchanged`, `InSync`, `Foreign`, `Jump`, `Desync`) and computing retry suffixes.
- `botnav::ZPortalGraph`, `botnav::ZPortal`, `botnav::planZRoute`, `botnav::zSnapLandingT` (`[bot_zcore.hpp:botnav::ZPortalGraph]`, `[bot_zcore.hpp:botnav::planZRoute]`): Dependency-free multi-floor portal graph and Dijkstra cross-floor route planner.
- `botnav::NavDump` (`[bot_navdump.hpp:botnav::NavDump]`): Binary map-dump serialization format (`BNDV` v1/v2) for offline pathfinding simulation.
- `botbrain::Channel`, `botbrain::TelemetryOutbox`, `botbrain::Session`, `botbrain::Runtime`, `botbrain::validate` (`[bot_brain_channel.hpp:botbrain::Channel]`, `[bot_brain_channel.hpp:botbrain::Runtime]`, `[bot_brain_protocol.hpp:botbrain::validate]`): Non-blocking AF_UNIX datagram channel, bounded telemetry outbox, and intent validation protocol for external pilot brains.
- `botsupplies::PotionDef`, `botsupplies::kPotions`, `botsupplies::vocBit` (`[bot_potions.hpp:botsupplies::PotionDef]`, `[bot_potions.hpp:botsupplies::kPotions]`): Vocation and level-gated potion definitions.

## Invariants
- `botEngineAbiTag()` must match `BOT_ENGINE_ABI_TAG` before `BotEngineLoader::prepare` invokes factory or vtable symbols (`[bot_engine_abi.hpp:BOT_ENGINE_ABI_TAG]`, `[bot_engine_loader.cpp:BotEngineLoader::prepare]`).
- All `BotEngine` tick, wake, hibernate, and chat callbacks execute on the single serial dispatcher thread (`[bot_engine_impl.hpp:botThreadCpuUs]`).
- When authored CSV loading fails, `dataPoisoned_` is set and `activateBot` refuses all bot activations rather than running on partial or empty data (`[bot_engine.cpp:BotEngine::activateBot]`).
- Hibernated bots preserve their `Player` instance in `hibernationPool_` while unlinked from `g_game().getPlayers()` and the world map; bots with active cast viewers (`getCastViewerCount() > 0`), human-led party members, or dying state (`dyingBots_`) must not hibernate (`[bot_engine.cpp:BotEngine::hibernateBot]`).
- Reload snapshots (`BotReloadSnapshot`) transfer only value types and executable-owned `std::shared_ptr<Player>` handles across `dlclose()`, cancelling pending dispatcher events (`cancelPendingDispatcherEvents`) before unloading the old module (`[bot_engine.cpp:BotEngine::quiesceForReload]`, `[bot_engine_loader.cpp:BotEngineLoader::commitReload]`).
- Real-player PvP protection: AoE rune targeting (`findBestRunePosition`) rejects candidate landing tiles within Chebyshev distance `<= 1` of any non-bot player, and both `checkVigilante` and `checkRandomPK` explicitly skip non-bot players (`!p->isBotPlayer()`) (`[bot_combat.cpp:BotEngine::findBestRunePosition]`, `[bot_combat.cpp:BotEngine::checkVigilante]`, `[bot_combat.cpp:BotEngine::checkRandomPK]`).
- Cross-floor portal planning caps hop depth at `BotEngine::Z_MAX_HOPS = 16` (`botnav::ZPlanParams::maxHops = 16`) with a 4,096-portal Dijkstra settle budget (`[bot_engine_impl.hpp:BotEngine::Z_MAX_HOPS]`, `[bot_zcore.hpp:botnav::ZPlanParams]`).
- `BotAuditSink` rotates at `botAuditMaxMb` (keeping one `.1` generation), uses wall-clock `epochMs()` instead of cycle-cached `OTSYS_TIME()`, and auto-disables after 5 consecutive writes slower than 50 ms (`[bot_audit_sink.hpp:BotAuditSink]`).
- Player command verbs (`[bot_verb.cpp]`) enforce the four-tier security ladder (`STRANGER`, `PARTY`, `LEADER`, `GM`), refuse red/black-skulled speakers below `GM`, and share one `handleVerb` parser across PM, party chat, and ExtendedOpcode `120`.
- Depot sparring (`[bot_spar.cpp]`) pairs only engine-owned bots, aborts immediately if a skull appears, and caps each strike to avoid lethal burst hits.

## Side Effects
- Copies `libbot_engine.so` into a private `mkdtemp` directory and loads/unloads it via `dlopen` / `dlclose` (`[bot_engine_loader.cpp:BotEngineLoader::prepare]`, `[bot_engine_loader.cpp:BotEngineLoader::Module::~Module]`).
- Mutates world state by placing, moving, teleporting, equipping, and removing bot `Player` instances in `Game` and `Map`, casting spells, using items, and dispatching chat messages (`[bot_engine.cpp:BotEngine::materializePlayerFromDb]`, `[bot_engine.cpp:BotEngine::activateBot]`, `[bot_engine.cpp:BotEngine::deactivateBot]`).
- Executes synchronous and asynchronous SQL queries via `Database` and `g_botDatabaseTasks()` (`bot_active_players`, `cast_broadcasters`, `bot_state_persistence`, `bot_hunt_danger`) and checkpoints player state via `g_saveManager()` (`[bot_engine.cpp:BotEngine::registerBot]`, `[bot_engine.cpp:BotEngine::checkpointBotPersistentState]`, `[bot_engine.cpp:BotEngine::saveAllStates]`, `[bot_learning.cpp]`).
- Reads and writes authored CSV/JSON/binary cache files under `data/bot/` and `data/bot_chat/`, writes synchronous NDJSON audit logs via `BotAuditSink::write`, and binds non-blocking Unix domain sockets (`server.sock`, `server.lock`) when `botbrain::Runtime` is enabled (`[bot_brain_channel.hpp:botbrain::Channel]`, `[bot_audit_sink.hpp:BotAuditSink]`, `[bot_engine_impl.hpp:BotEngine]`).
- When QA environment variable `CANARY_QA_HUNT_PHASE_TRACE_GUID` matches a bot's GUID, `BotEngine::beginHuntPhase` emits passive `[HUNT:PHASE]` transition log lines (`[bot_hunt.cpp:BotEngine::beginHuntPhase]`).
