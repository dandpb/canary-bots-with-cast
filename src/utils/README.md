# utils

## Overview
Provides foundational data structures, lock-free memory pools, string/time/math/random utilities, XML numeric casting, stack trace symbolization, prefix wildcard trees, SIMD intrinsics headers, and global protocol/item constants and enumerations.

## Interface
- Containers & Hashing: `stdext::arraylist` (`[arraylist.hpp:stdext::arraylist]`), `stdext::vector_set` (`[vectorset.hpp:stdext::vector_set]`), `stdext::vector_sort` (`[vectorsort.hpp:stdext::vector_sort]`), `stdext::hash`, `stdext::hash_int`, `stdext::hash_union`, `stdext::hash_combine` (`[hash.hpp:stdext::hash]`, `[hash.hpp:stdext::hash_int]`, `[hash.hpp:stdext::hash_union]`, `[hash.hpp:stdext::hash_combine]`), and `TransparentStringHasher` (`[transparent_string_hash.hpp:TransparentStringHasher]`).
- Memory & Pointer Management: `LockfreeFreeList` & `LockfreePoolingAllocator` (`[lockfree.hpp:LockfreeFreeList]`, `[lockfree.hpp:LockfreePoolingAllocator]`), `ObjectPool` (`[object_pool.hpp:ObjectPool]`), and `SharedPtrManager` & `g_counterPointer` (`[counter_pointer.hpp:SharedPtrManager]`, `[counter_pointer.hpp:g_counterPointer]`).
- Profiling & Diagnostics: `Benchmark` (`[benchmark.hpp:Benchmark]`), `printXMLError` (`[tools.hpp:printXMLError]`), `printStackTrace` (`[tools.hpp:printStackTrace]`), and `consoleHandlerExit` (`[tools.hpp:consoleHandlerExit]`).
- XML & String/Math/Time/Random Utilities: `pugi::cast` & `pugi::logError` (`[pugicast.hpp:pugi::cast]`, `[pugicast.hpp:pugi::logError]`), `WildcardTreeNode` (`[wildcardtree.hpp:WildcardTreeNode]`), `transformToSHA1` (`[tools.hpp:transformToSHA1]`), `generateToken` (`[tools.hpp:generateToken]`), RNG helpers (`[tools.hpp:getRandomGenerator]`, `[tools.hpp:uniform_random]`, `[tools.hpp:normal_random]`, `[tools.hpp:boolean_random]`), time helpers (`[tools.hpp:getTimeNow]`, `[tools.hpp:getTimeMsNow]`, `[tools.hpp:getTimeUsNow]`, `[tools.hpp:OTSYS_TIME]`, `[tools.hpp:UPDATE_OTSYS_TIME]`), string/formatting helpers (`[tools.hpp:replaceString]`, `[tools.hpp:explodeString]`, `[tools.hpp:split]`, `[tools.hpp:toLowerCaseString]`, `[tools.hpp:asLowerCaseString]`, `[tools.hpp:asUpperCaseString]`, `[tools.hpp:toCamelCase]`, `[tools.hpp:toPascalCase]`, `[tools.hpp:toSnakeCase]`, `[tools.hpp:toKebabCase]`, `[tools.hpp:toKey]`, `[tools.hpp:validateName]`), and game/enum conversion helpers (`[tools.hpp:getNextPosition]`, `[tools.hpp:getDirectionTo]`, `[tools.hpp:getPrimaryDirection]`, `[tools.hpp:combatTypeToIndex]`, `[tools.hpp:getReturnMessage]`, `[tools.hpp:calculateEquipmentLoss]`, `[tools.hpp:calculateMaxPvpReduction]`, `[tools.hpp:getVocationIdFromClientId]`).
- Constants, Macros, & Definitions: `MAX_LOOTCHANCE`, `NETWORKMESSAGE_MAXSIZE`, `INPUTMESSAGE_MAXSIZE`, `CHANNEL_*`, `PSTRG_*`, `isStorageKeyInRange` (`[const.hpp:MAX_LOOTCHANCE]`, `[const.hpp:NETWORKMESSAGE_MAXSIZE]`, `[const.hpp:isStorageKeyInRange]`), platform/compiler macros (`[definitions.hpp:__METRICS_METHOD_NAME__]`, `[simd.hpp:mm_ctz]`), and utility enums (`[utils_definitions.hpp:WieldInfo_t]`, `[utils_definitions.hpp:SpawnType_t]`, `[utils_definitions.hpp:Cipbia_Elementals_t]`, `[utils_definitions.hpp:MagicEffectClasses]`, `[utils_definitions.hpp:ShootType_t]`, `[utils_definitions.hpp:SpeakClasses]`, `[utils_definitions.hpp:MessageClasses]`, `[utils_definitions.hpp:Fluids_t]`, `[utils_definitions.hpp:TextColor_t]`, `[utils_definitions.hpp:WeaponType_t]`, `[utils_definitions.hpp:Ammo_t]`, `[utils_definitions.hpp:Skulls_t]`, `[utils_definitions.hpp:PartyShields_t]`, `[utils_definitions.hpp:GuildEmblems_t]`, `[utils_definitions.hpp:NameEval_t]`, `[utils_definitions.hpp:ItemID_t]`, `[utils_definitions.hpp:PlayerFlags_t]`, `[utils_definitions.hpp:BedItemPart_t]`, `[utils_definitions.hpp:AttrSubId_t]`, `[utils_definitions.hpp:Concoction_t]`, `[utils_definitions.hpp:Screenshot_t]`).

## Invariants
- `stdext::arraylist`, `stdext::vector_set`, and `stdext::vector_sort` defer ordering/merging via `needUpdate = true` on insertion and lazily reconcile (`update()`) before reads or iterations (`[arraylist.hpp:stdext::arraylist::update]`, `[vectorset.hpp:stdext::vector_set::update]`, `[vectorsort.hpp:stdext::vector_sort::update]`).
- `pugi::cast<T>` clamps parsed numeric values to `[std::numeric_limits<T>::lowest(), std::numeric_limits<T>::max()]` and returns `T{}` on parse errors (`[pugicast.hpp:pugi::cast]`).
- `PlayerFlags_t::FlagLast` must always remain the final enumerator of `PlayerFlags_t` (`[utils_definitions.hpp:PlayerFlags_t]`).
- `validateName` requires character names to be 3–18 characters long, match `^[a-zA-Z' ]+$`, contain tokens of length >= 2, and exclude prohibited words (`[tools.cpp:validateName]`).

## Side Effects
- `LockfreeFreeList::preallocate` and `LockfreePoolingAllocator` allocate and deallocate raw aligned heap memory and mutate a static `atomic_queue::AtomicQueue2` free list (`[lockfree.hpp:LockfreeFreeList::preallocate]`, `[lockfree.hpp:LockfreePoolingAllocator::allocate]`, `[lockfree.hpp:LockfreePoolingAllocator::deallocate]`).
- `UPDATE_OTSYS_TIME` mutates the global `OTSYSTIME` timestamp variable (`[tools.cpp:UPDATE_OTSYS_TIME]`), and RNG helpers mutate the static `std::mt19937` state in `getRandomGenerator()` (`[tools.cpp:getRandomGenerator]`).
- `printXMLError` opens and reads the target XML file from disk (`fopen`/`fread`) and logs line context via `g_logger()` (`[tools.cpp:printXMLError]`).
- `consoleHandlerExit` blocks on `getchar()` when `STDIN_FILENO` is a TTY (`[tools.cpp:consoleHandlerExit]`), and `sleep_for` blocks the calling thread (`[tools.cpp:sleep_for]`).
- `printStackTrace` initializes the Abseil symbolizer (`absl::InitializeSymbolizer`) and logs stack frames when log level is not `"info"` (`[tools.cpp:printStackTrace]`).
