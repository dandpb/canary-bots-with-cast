# MyAAC Plugins (`plugins`)

## Overview

MyAAC plugin directory containing the `worldmap.json` plugin manifest and the `worldmap/` live character map plugin package.

## Subdirectories & Boundaries

- `worldmap`: [`./worldmap/README.md`](./worldmap/README.md) — Live MyAAC Community map plugin (`config.php`, `install.php`, `pages/worldmap.php`, `static/worldmap.js`) plotting online character coordinates across Overview and per-floor minimap layers.
